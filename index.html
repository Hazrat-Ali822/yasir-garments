Google Sheets Sync

Apna Google Apps Script Web App URL paste karein taake saara data Google Sheet me save ho.

  1. Open sheets.google.com → create a blank sheet, name it Yasir Garments.
  2. Top menu: Extensions → Apps Script.
  3. Delete any code there, paste the full Code.gs file I gave you, then click Save.
  4. Click Deploy → New deployment → gear icon → Web app.
  5. Set Execute as: Me, Who has access: Anyone, then Deploy and allow the permissions.
  6. Copy the Web app URL (ends with /exec) and paste it in the box above.
  7. Tap Sync to Sheets now. Done — every sale/return ab Sheet me save hoga.
